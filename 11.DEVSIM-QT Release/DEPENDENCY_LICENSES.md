This archive contains project source and generated measurements, not the Python wheels or native system libraries. Pinned direct dependencies are in requirements.txt. Installed wheel license notices are reproduced under licenses/ with metadata in licenses/DEPENDENCIES.json. Consult those original notices for redistribution obligations (including Gmsh and DEVSIM); this document does not replace them.

This delivery to the owner does not invent or grant a new third-party license to the inherited project. The owner should establish an explicit project license before public redistribution.

SIESTA source, school-private files, credentials, external git metadata, virtual environments, and system native libraries are excluded. Uploaded SIESTA was not used to build this EMA/NEGF release candidate. AI training, DFT corrections, phonon scattering and DD were not added.
